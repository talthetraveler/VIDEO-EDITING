# FORMAT — Startup / Technology Story

> **PROVISIONAL.** No approved Tal video in this format has been measured. Built
> from `MOTION-PROMPT.md` (MODE B), the NAS explainer measurements, and the
> stated MODE A/B split. **Correct from the first real approval.** **[?]**

The one format where motion graphics legitimately lead. A product, a company,
a system — things with no human face to hold.

| | |
|---|---|
| **Title card** | Centre reveal card, not the street pill |
| **Captions** | Sentence case, bottom third y ≈ 0.76, keyword emphasis (NAS family) |
| **Hook** | The surprising claim or number, stated in the first line |
| **Pacing** | 16–27 cuts/min. Faster where information is dense |
| **B-roll** | Real product/UI assets first, generated imagery last |
| **Graphics** | **Heavy — this is MODE B.** Numbers get their own full-screen beat |
| **Music** | Continuous bed |
| **Runtime** | 60–150s |
| **Natural audio** | Minimal — VO-led |

## MODE B rules

Premium dark-motion language: true black, light reveals objects, dark matte
glass, a cyan → violet → magenta arc, **brand colour as the hero**, cinematic
camera moves, visual-native transitions or hard cuts. Beat sheets of 4–7 beats,
**one idea per beat, 2–6 words on screen.** Full spec in `MOTION-PROMPT.md`;
components in `src/components/motion/`. **[S]**

## Visual hierarchy — use the strongest available, always

**human footage > real story footage > product/UI > screenshots > maps >
data-viz > typography > diagrams > generated imagery.**

AI-generated visuals **only** when there is no stronger real option. **[S]**

## Failure states

- Motion graphics because Remotion can, not because they clarify **[S]**
- Corporate-cheese animation, transition spam, generic AI gradients, floating 3D
  icons, clutter **[S]**
- A stat as a number over stock footage instead of its own animated moment **[S]**
- Forgetting there is usually still a person in the story. If there is one, they
  outrank every graphic
