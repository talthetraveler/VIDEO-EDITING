An organisation, a cause, a mission. The trap is making it feel like a
promotional film. **It has to stay a human story that happens to involve an
organisation.**

| | |
|---|---|
| **Title card** | Yes. Lead with the human or the mission, not the org name. Top y ≈ 0.11 |
| **Title hold** | ~35s |
| **Captions** | White caps, one word gold, 2–3 words, y ≈ 0.60–0.67, speech-only |
| **Hook** | Kind C (payoff-line cold open) — one person's line, never a mission statement |
| **Pacing** | Conversation pace, with a faster middle if there are facts to land |
| **B-roll** | The work being done. Only what is named |
| **Graphics** | A number gets its own beat. Otherwise none |
| **Music** | Low, warm, under |
| **Runtime** | 60–120s |
| **Natural audio** | High |

## Structure

**Person → problem → what they do → proof → emotional payoff.**

Lead with **one person inside the organisation**, not the organisation. The
mission is revealed through what they are doing, not stated up front. This is
the bible's "human first / reveal progressively" applied to an institution. **[S]**

## Failure states

- Opening on a logo, a mission statement, or a founder explaining the mission
- Stat-stacking. One number per beat, and only if it changes what you feel
- B-roll of buildings and meetings. Show the work, or a face
- Slipping into MODE B (motion graphics). This stays MODE A — real footage **[S]**
