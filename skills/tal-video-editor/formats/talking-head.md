# FORMAT — Talking Head

One person speaking to camera, unscripted or lightly scripted. No VO layer.
The face carries it.

| | |
|---|---|
| **Title card** | Optional. If the identity is the hook, use the pill at top y ≈ 0.11 |
| **Title hold** | `hook` ~6s, or none |
| **Captions** | White caps, one word gold, 2–3 words, y ≈ 0.60–0.67, speech-only |
| **Hook** | Kind C (lift the best later line to 0:00) if there is one worth lifting |
| **Pacing** | **Moderate. Hold the face.** Cut fillers and dead air, not breath |
| **B-roll** | Light. Insert only where a noun is named |
| **Graphics** | Captions only unless a number needs a beat |
| **Music** | Optional, low |
| **Runtime** | 30–90s |
| **Natural audio** | Keep the room / street |

## The single-take option

**6 of 7 top Montana Tucker verticals are ONE UNBROKEN SHOT** — zero cuts, zero
on-screen text, 14–43s, locked-off wide, full body. **[M]**

That is a real, deliberate choice, not laziness: **don't cut a moment that is
working.** If the take holds, ship the take. Transferable detail from the same
analysis: a **1-second object cold-open before a face**, and subject/background
colour contrast. **[M]**

## Where this format goes wrong

- **Cutting for the sake of a cut rate.** If the take is working, leave it.
- Trimming breath and micro-pauses until the delivery sounds robotic. Cut dead
  air, not the space around a sentence.
- Captions held across a pause while the person is thinking. Speech-only.

## If it needs to be fast

If the brief is a fast, cutaway-heavy talking-head piece (script or VO, kinetic
type, news stacks), that is a **different format** — use `social-accords`. It
runs ~41 cuts/min against this format's moderate pace. Choosing wrong between
these two has produced a rejected edit before. **[S]**
